Automatic cooling

During the schedule, LocalAIR turns the AC on when the room gets warm and off once it has cooled. When the schedule ends it turns the AC off once and leaves it to you.

Sensor connection

The Tuya temperature and humidity sensor, which also sends the IR commands to the AC. Find these values with the TinyTuya wizard.

Advanced

History storage and the web server. You won't normally need to change these.

!

Changes to the web host or port take effect after LocalAIR restarts.
